# 🛒 বাজার দর | BazarDor

**Daily essential market prices in Bangladesh, at a glance.**

BazarDor is a Bengali-language web application that helps users explore daily product prices, track price changes, and compare market prices across Bangladesh.

🔗 **Live Demo:** [BazarDor](https://bazar-mart-next-js.vercel.app/)  
📦 **GitHub Repository:** [BazarDor](https://github.com/TaheraScript/BazarDor)

## ✨ Key Features

1. **📊 Daily Price Tracking** — View essential product prices and daily price changes.
2. **🗂️ Category Browsing** — Explore products by category with convenient sorting options.
3. **🏪 Market Price Comparison** — Compare minimum, maximum, and average prices across markets.
4. **🔐 Secure Authentication** — Sign in and sign up using email/password, Google, or GitHub.
5. **📱 Responsive Design** — Enjoy a clean interface with Bengali text and numerals across devices.

## 🧰 Technologies Used

- **Framework:** Next.js, React
- **Language:** TypeScript
- **Styling:** Tailwind CSS, daisyUI
- **Authentication:** Better Auth
- **Database:** MongoDB
- **UI Libraries:** React Icons, react-hot-toast
- **Deployment:** Vercel
